辅助数据
========

Satpy 使用各种辅助数据文件来执行某些操作，例如大气校正和角度计算。

辅助数据类型
============

Satpy 使用的常见辅助数据类型包括：

* **地形数据** - 用于地形校正
* **大气数据** - 用于瑞利散射校正
* **查找表** - 用于各种校正和转换
* **系数数据** - 用于校准

自动下载
========

Satpy 可以自动下载所需的辅助数据。这由配置设置控制：

.. code-block:: python

    import satpy
    satpy.config.set(download_aux=True)

数据位置
========

辅助数据存储在由 ``data_dir`` 配置设置指定的目录中。

提供自定义辅助数据
==================

您可以通过将文件放在适当的目录中来提供自己的辅助数据文件。

.. note::

    有关特定辅助数据要求的详细信息，请参阅各个组件的文档。

贡献指南
========

感谢您对 Satpy 的贡献感兴趣！本文档提供了有关如何为 Satpy 项目做出贡献的指导。

.. _dev_help:

获取帮助
========

如果您在贡献过程中需要帮助，可以通过以下方式联系我们：

* 在 GitHub 上创建问题：https://github.com/pytroll/satpy/issues
* 加入 Pytroll Slack 团队
* 发送邮件到 Pytroll 邮件列表

贡献类型
========

有许多方式可以为 Satpy 做出贡献：

* 报告错误
* 提出新功能
* 编写或改进文档
* 提交代码修复或新功能
* 审查拉取请求

代码贡献流程
============

1. Fork Satpy 存储库
2. 创建一个新分支用于您的功能或修复
3. 进行您的更改
4. 添加测试以覆盖您的更改
5. 确保所有测试通过
6. 提交拉取请求

.. note::

    有关详细的贡献指南，请参阅 `Pytroll 贡献指南 <http://pytroll.github.io/guidelines.html>`_。

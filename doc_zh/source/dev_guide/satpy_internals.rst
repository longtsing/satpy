Satpy 内部机制
==============

本文档描述了 Satpy 的内部架构和设计决策。

核心概念
========

Scene（场景）
-------------

Scene 是 Satpy 的主要接口，代表一组数据集和相关元数据。

DataID
------

DataID 用于唯一标识数据集。它包含：

* name - 数据集名称
* wavelength - 波长（如果适用）
* resolution - 空间分辨率
* calibration - 校准类型
* modifiers - 应用的修饰符

依赖树
------

Satpy 使用依赖树来管理数据集之间的关系和依赖项。这允许：

* 自动加载前提条件
* 延迟计算
* 高效的资源管理

读取器接口
==========

读取器负责从文件中读取数据并将其转换为 DataArray 对象。

合成器接口
==========

合成器组合多个数据集以创建新的派生产品。

.. note::

    有关 Satpy 内部的更多技术细节，请参阅源代码和 API 文档。

XArray 迁移指南
===============

本指南帮助开发者了解如何使用 XArray 和 Dask 来开发 Satpy。

为什么使用 XArray？
==================

XArray 为处理标记的多维数组提供了强大的抽象。它允许 Satpy：

* 使用命名维度而不是位置索引
* 存储丰富的元数据
* 与其他科学 Python 库轻松集成

使用 Dask 进行延迟计算
=====================

Satpy 大量使用 Dask 进行延迟计算和并行处理。这意味着：

* 数据操作是延迟的，直到明确请求结果
* 大型数据集可以高效处理
* 操作可以自动并行化

最佳实践
========

1. 始终保留元数据
2. 使用命名维度进行索引
3. 利用延迟计算
4. 注意内存使用

.. note::

    有关使用 XArray 和 Dask 的更多详细信息，请参阅它们各自的文档。

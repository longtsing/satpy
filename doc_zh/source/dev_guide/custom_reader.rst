创建自定义读取器
================

本指南介绍如何为 Satpy 创建自定义读取器以支持新的数据格式。

读取器基础
==========

Satpy 读取器是负责读取特定文件格式并将数据转换为 Satpy 可以使用的 XArray DataArray 对象的 Python 类。

基本读取器结构
==============

一个基本的读取器通常包括：

1. 配置文件（YAML）- 定义读取器元数据和数据集
2. Python 类 - 实现实际的文件读取逻辑

步骤
====

1. 创建读取器配置文件
2. 实现读取器类
3. 定义数据集
4. 处理地理定位
5. 添加测试

示例
====

有关完整的读取器示例，请参阅 Satpy 源代码中的现有读取器。
